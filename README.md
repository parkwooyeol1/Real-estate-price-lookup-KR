# 부동산 공시가격 통합조회

주소 한 줄만 붙여넣으면 유형을 자동 판별해
**개별공시지가 · 개별단독주택가격 · 공동주택가격** 중 해당 정보를 보여주는 프로그램.

- 사용자는 토지/단독/공동주택을 직접 고르지 않는다. 프로그램이 알아서 판별한다.
- 데이터는 **브이월드(VWorld) 국가중점데이터 API** 한 곳으로 전부 조회한다.
  (공공데이터포털 data.go.kr 키는 필요 없음)

## 기존 방식 대비 개선점

예전엔 **부동산공시가격알리미 사이트를 드롭다운으로 왕복하고, 계산기로 ×1.3·지분을 일일이 두드려 한 건씩** 처리했습니다.
이제 **주소만 넣으면 판별·조회·환산·지분계산이 자동으로 끝나고, 최대 10곳을 한눈에** 볼 수 있습니다.

| 과거 (알리미 사이트 수기 조회) | 개선 (이 프로그램) |
|---|---|
| 시/도·시군구·읍면동 드롭다운을 일일이 클릭 | 주소 붙여넣기 한 번 → 자동 파싱·라우팅 |
| 토지/단독/공동주택을 따로 조회 | 유형 자동 판별해 한 번에 조회 |
| 단지 → 동 → 호를 수동 선택 | 주소에 있으면 바로, 틀리면 목록 버튼으로 선택 |
| 공시가를 계산기에 옮겨 ×1.3 | 자동 환산(×1.3) 표시 |
| 소유지분을 계산기로 또 곱함 | 주소별 지분 입력 → 자동 반영 |
| 부동산 개수만큼 한 건씩 반복 | 최대 10건 일괄 조회 |
| 결과를 따로 메모 | '한눈에 보기'로 전 주소 환산가·계산과정 모아보기 + 클릭 복사 |

### 핵심 기능

- **주소 자동 판별** — 지번·도로명 모두 인식, 토지·단독주택·공동주택 자동 구분
- **다중 주소 일괄 조회(최대 10개)** — '+ 주소 추가', 주소별 결과 블록
- **주소별 개별 소유지분** — 블록마다 독립 지분, `공시가격 × 1.3 × 지분` 자동 계산
- **환산가격 한눈에 보기** — 전 주소 환산가 + 계산과정 + 지분 반영, 금액 클릭 복사
- **🗺 지도 보기** — 조회한 '바로 그 필지'를 VWorld 지도(지적경계 오버레이)에 마커로 표시 (브라우저)
- **국토부 실거래가** — 같은 필지의 실제 거래가(국토교통부 RTMS)를 함께 조회해 공시가격과 비교
- **엑셀 · PDF 내보내기** — 다중 주소의 공시가격·환산액·지분반영액을 표로 저장
- 결과에 조회 주소 표시, 소수 4자리 표시·정수 복사, 초기화 버튼

### 데이터 융합 (공간정보 + 공공데이터)

| 데이터 | 출처 | 용도 |
|---|---|---|
| 주소→PNU·좌표, 공시가격, 지도/지적 | 브이월드(VWorld) 국가중점데이터·지도 API | 핵심 조회·지도 |
| 실거래가(매매) | 국토교통부 실거래가(RTMS, 공공데이터포털) | 공시가격 대비 실거래가 비교 |

### 사이트에서도 까다롭던 케이스까지 자동 처리

- 한글 동(제가동·가/나/다동), 동 없는 단지(주상복합·호만), 동 저장형식 차이(`3` · `108동` · `가`)
- 여러 필지(외 N필지) → 데이터 있는 대표지번 후보 제시 후 선택
- 동/호가 틀리면 → 실제 동·호 목록을 버튼으로 띄워 골라 재조회

### 현재 제약 — 인천 신설 4개 구 미반영

원인은 프로그램이 아니라 데이터 공급원(VWorld API)의 갱신 시차입니다.
2026-07-01 개편으로 생긴 인천 **제물포·영종·검단·서해구**는 알리미(원천)엔 값이 있지만 VWorld API엔 새 행정코드가 아직 미반영되어 조회되지 않습니다. 프로그램은 엉뚱한 값을 내지 않고 '조회하지 못했습니다(미반영)'로 명확히 안내하며, VWorld가 코드를 적재하면 수정 없이 자동으로 조회됩니다.

- 전남광주통합특별시: 옛 코드 자동 폴백으로 정상 조회
- 그 외 전국: 정상
- 인천 신설 4개 구: 미반영(알리미에서 직접 확인 필요)

## 소스로 실행

```bash
pip install -r requirements.txt
python main.py
```

Python 3.10 이상 권장. Tkinter는 표준 라이브러리, UI는 customtkinter 사용.

주소 입력 예:

| 유형 | 입력 예 |
|---|---|
| 토지 | `서울특별시 강남구 역삼동 808` |
| 단독주택 | `서울특별시 종로구 가회동 11` |
| 공동주택 | `서울특별시 강남구 대치동 316 27동 1401호` |

공동주택인데 동/호를 안 넣으면, 단지의 동 목록을 안내하니 `○동 ○호`를 붙여 다시 조회하면 된다.

## 설정 (인증키)

**브이월드(VWorld) — 필수** (공시가격·지도)
- 발급: https://www.vworld.kr → 마이페이지 > 인증키 관리
- 실행파일 옆 `vworld_key.txt` (1줄=키, 2줄=도메인) 로 재빌드 없이 갱신. `vworld_key.example.txt` 참고.

**공공데이터포털(data.go.kr) — 실거래가용(선택)**
- 발급: https://www.data.go.kr → 로그인 → 아래 4개 서비스 **활용신청**(승인 필요) → 마이페이지 > 인증키에서 **일반 인증키(Decoding)** 복사
  - 국토교통부_아파트 매매 실거래가 / 연립다세대 / 단독·다가구 / 토지 매매 실거래가
- 실행파일 옆 `datago_key.txt` (1줄=키) 로 설정. `datago_key.example.txt` 참고. **키가 없으면 실거래가 기능만 비활성**되고 나머지는 정상 동작합니다.

## 동작 원리 (자동 판별)

1. 입력에서 `숫자+동 / 숫자+호` 패턴을 분리 (법정동 "역삼동" 등은 건드리지 않음)
2. 나머지 기본주소를 PNU로 변환
3. PNU로 공동주택가격 데이터가 있으면 → **공동주택**, 없으면 → **토지/단독주택**
4. 유형에 맞는 API로 조회 후 결과 표시

## 확정된 VWorld API 응답 필드 (실제 호출로 검증, 2026-07 기준)

| 항목 | 엔드포인트 | 핵심 필드 |
|---|---|---|
| 주소→PNU | `/req/search` | `result.items[0].id` |
| 개별공시지가 | `/ned/data/getIndvdLandPriceAttr` | `pblntfPclnd`(원/㎡), `stdrYear` — 연도별 다건이라 최신 선택 |
| 토지특성 | `/ned/data/ladfrlList` | `lndcgrCodeNm`(지목), `lndpclAr`(면적) — 최상위 `ladfrlVOList.ladfrlVOList` |
| 단독주택가격 | `/ned/data/getIndvdHousingPriceAttr` | `housePc`(원), `stdrYear` |
| 공동주택가격 | `/ned/data/getApartHousingPriceAttr` | `aphusNm`(단지), `dongNm`,`hoNm`, `prvuseAr`(전용면적), `pblntfPc`(원) — `dongNm`/`hoNm` 파라미터로 세대 필터 가능 |
